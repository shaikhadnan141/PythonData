📌 Python Portfolio Code Viewer

This project is a beautiful portfolio website that displays your Python files directly in the browser.
It includes:

✅ Modern UI
✅ Sidebar file explorer
✅ Code viewer with clean formatting
✅ Fully responsive
✅ Works directly on GitHub Pages

🚀 Features
📁 Auto file list — All Python files appear in the sidebar
👀 Click to view — Clicking any file shows its code instantly
🎨 Dark themed UI — Modern GitHub-like look
⚡ Pure HTML + CSS + JS — No frameworks required
🌐 One-click deploy on GitHub Pages
📂 Project Structure
/
├── index.html        # Main website
├── README.md         # Project documentation
├── Dictionary/       # Your Python folders
├── List & Tupple/
└── string/

Make sure your Python files stay in the same structure, because the website loads them dynamically.

🔧 How to Use
1️⃣ Clone this repo
git clone https://github.com/your-username/your-repo.git
2️⃣ Add your Python project files

Keep all .py files exactly in their folders (as already uploaded).

3️⃣ Add index.html to the root

The website will automatically show all Python files that you listed inside JavaScript.

4️⃣ Open the website

Just double-click:

index.html

Your portfolio works instantly!

🌐 Deploy on GitHub Pages
Open your repo on GitHub
Go to Settings → Pages
Select:
Branch: main
Folder: / (root)
Click Save

Your website will be live at:

https://your-username.github.io/your-repo/
